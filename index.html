Capabilities

Everything a Senior QA Engineer does.
Running 24/7.

🤖
Real App. Real Screens.
Drives the Toast Operator Production app via Appium XCUITest. No mocks, no stubs, no simulators of simulators. Every test hits real accessibility identifiers that ship in the product.
⚡
Deep Self-Healing — 113 Points
Multi-candidate waits, retry loops, native nav-bar fallback, scroll-to-reveal, atomic field replacement. The agent adapts when developers rename identifiers or refactor views.
🧠
Dynamic Flow Generator
No pre-built flow? AI generates one from the PR diff — fetches the unified diff from GitHub, sends it to GPT-4o with the Jira AC, gets back a custom test sequence. Hallucinated actions are safety-filtered.
✍️
AI Writes Its Own Test Code
LocatorCodegen scans Swift source for new accessibility IDs. FeatureCodegen uses OpenAI to generate action methods, flow JSON, keyword mappings, and orchestrator handlers — all inserted live.
🎤
Voice Commands
Click the mic and speak: "Run full regression", "Test invoice scanning", "SMB-1168". Web Speech API, in-browser, no plugins. The agent picks the right flow automatically.
🐛
One-Tap Bug Filing
Any failed run shows a 🐛 File Bug button. One click creates a linked Jira bug ticket with failure detail, steps to reproduce, run ID, and feature context — pre-filled.
🎬
Full Video Recording
Every run recorded as an MP4 using simctl recordVideo. Solves the EBUSY lock problem on session reuse. Video appears in the dashboard and is attached to Jira automatically.
🔭
Leadership Copilot
Preflight analysis before every run: change detection, risk assessment, scenario generation, flow recommendation. The Strategic Insight Trace shows WHY the agent chose the test it ran.
🛠️
Always Tests the Latest Build
The dashboard tracks how many commits the installed simulator app is behind origin/main and shows a live freshness badge. One tap rebuilds the Toast Operator app with xcodebuild, streams the build log, verifies the scheme/bundle, and stamps the new SHA — so you never test stale code.
Sprint Bug Bash

Test your entire sprint.
One tap.

Every two weeks the team sits together, reads out sprint tickets one by one, and tests each one manually. It's slow. It's exhausting. It misses things.

ToastPilot replaces the entire bug bash session with a single paste-and-click. Paste all sprint ticket IDs, hit Run — ToastPilot tests every ticket sequentially, attaches evidence to each Jira ticket, and sends an aggregate Slack summary when done.

Self-Healing

Tests that fix
themselves.

Selectors break when developers rename identifiers or refactor views. Traditional test automation fails immediately. ToastPilot doesn't.

113 healing touchpoints across multi-candidate waits, retry loops, scroll-to-reveal, atomic text replacement, and a fuzzy page-source scanner that finds the element even when the ID changed.

Build Freshness

Never tests
stale code.

A QA agent is only as good as the build it runs against. ToastPilot watches origin/main and knows exactly how many commits the installed simulator app is behind.

When the app is out of date, one tap rebuilds it with xcodebuild. The build runs detached, streams its log live to the dashboard, verifies the scheme and bundle ID, copies the .app into place, and stamps the new commit SHA — so every test runs against the freshest code automatically.
